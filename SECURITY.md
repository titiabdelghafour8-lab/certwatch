# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/titiabdelghafour8/certwatch/security/advisories/new).

You will get an acknowledgement within 72 hours. A fix or mitigation plan
follows within 14 days for confirmed issues, and you will be credited unless
you prefer otherwise.

## Supported versions

Only the latest minor release receives security fixes.

## Scope

In scope: the server, the CLI, the install scripts and the published container
image. Of particular interest: authentication bypass, cross-tenant access,
SSRF via monitored targets or webhooks, and webhook signature bypass.
